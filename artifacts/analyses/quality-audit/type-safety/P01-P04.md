# Type Safety — P01–P04 (full src + tools)

**Domain:** Type Safety  
**Scope:** `src/roxabi_sense/**/*.py`, `tools/**/*.py`, `pyrightconfig.json`, `pyproject.toml`  
**Date:** 2026-07-31  
**Mode:** Static audit (read-only; no source edits)

### Summary

The package is **reasonably annotated** for a small Python ≥3.13 sensor: almost all public callables carry param/return types, dataclasses dominate report/store models, `X | Y` is used consistently (no `Optional`/`Union` abuse), and pyright is pinned in dev deps with **`typeCheckingMode: "basic"`**.

The main debt is **schema erasure at JSON boundaries**: event payloads, agent sessions, agent links, AT-SPI window dicts, and IPC messages are almost everywhere `dict[str, Any]` / `list[Any]`. The `Collector` Protocol exists but is **not used** by daemon assembly (`list[Any]`). A few **`# type: ignore`** sites paper over a real union-boundary problem (`FocusAtspiCollector.apply`). The largest untyped island is **`atspi/agent_worker.py`** (explicitly excluded from pyright). Tools (`license_check.py`) use bare `dict`/`list` and are outside pyright `include`.

No P0 (runtime type holes that would silently corrupt store integrity by typing alone). Highest value fixes: wire `Collector` into `build_*`/`tick_*`, TypedDicts (or small dataclasses) for session/window/agent-link payloads, and remove the `apply` dual-list + ignore pair.

### Recommendations

1. **Wire the Protocol (TS-01)** — Highest ROI for basic mode: `list[Collector]` stops silent attribute mistakes and documents the tick contract.
2. **Normalize AT-SPI windows at the boundary (TS-03)** — Kill dual list + `type: ignore` by converting IPC dicts once in `apply_probe_result` / `probe_once`.
3. **TypedDict for stable fact shapes (TS-02, TS-04)** — Start with `AgentSession`, `AgentLink`, `FocusPayload`, `IdlePayload`, `DesktopWindow`. Do not need full codegen; hand-written TypedDicts are enough under basic/strict islands.
4. **Literalize config enums (TS-09, TS-10, TS-15)** — Single `NameEventsMode`, add `IdleBackend`, tighten Presence/AwaySegment string fields.
5. **Small hygiene (TS-07, TS-08, TS-13, TS-17)** — Annotate `sum_by.key`, fix CLI `dict`, replace Literal ignores with `cast`, tighten tuple aliases.
6. **Keep agent_worker excluded (TS-05)** — Document the JSON-line contract; type the host side only.
7. **CI** — Run `uv run pyright` in verify; optionally fail on new `# type: ignore` without code. Tools stay optional for pyright.
8. **Do not** raise whole-repo to `strict` before payload TypedDicts exist — noise will drown real issues; prefer island strictness on `store` + `report`.

# Code Smells — P1–P4 (src + tools)

**Scope:** `src/roxabi_sense/**/*.py`, `tools/**/*.py`  
**Audit date:** 2026-07-31  
**Gates (project):** file ≤300 lines (`tools/qg.conf`); audit focus also flags functions >50 LOC, files >400 LOC.

---

### Summary

The codebase is small (~35 production modules + 1 tools Python script) and generally well factored along the collector axis. The worst smells cluster in three places:

1. **`run_daemon` (~250 LOC)** — orchestration god-function with deep nesting (AT-SPI + idle respawn + poll deadlines).
2. **`atspi/agent_worker.py` (490 LOC, QG-exempted)** — module-level state machine; only file over 400 LOC.
3. **Cross-cutting DRY** — timestamp parse/format, fingerprint-and-skip collectors, dual subprocess agent lifecycles, and duplicated `tmux` / binary path resolution.

No P0 correctness smells in pure structure; highest severity is **P1** for the daemon loop size/complexity and the exempted AT-SPI worker module. Collectors themselves are mostly thin (≤110 LOC) with a clear `tick → fingerprint → append` pattern.

### Recommendations

**Priority order (smell reduction, not feature work)**

1. **Split `run_daemon` (SM-01)** before more respawn/MCP wiring — biggest cognitive load and near file-length gate.
2. **Centralize time helpers (SM-12)** — cheap win, eliminates subtle `strftime` vs `datetime` inconsistency between daemon stamps and store.
3. **Extract fingerprint helper (SM-13)** — unifies 4 collectors and reduces future copy-paste collectors (MCP/NATS won’t need this pattern).
4. **Plan `agent_worker` modularization (SM-02)** even if QG-exempted — 490 LOC with module globals is the highest latent defect surface.
5. **Kill or wire dead rate-limit paths (SM-18, SM-20)** — `FocusEventGate` + unused `source` confuse readers about where coalescing lives.
6. **Unify subprocess agents + tmux util (SM-14, SM-15)** when next touching idle/focus.
7. **Pass idle threshold into recap (SM-17)** so compile-time away gaps match runtime policy.

**What not to over-refactor**

- Individual collectors (agent_sessions, process_presence, mpris, tmux) are already small and readable.
- `Store` method surface is wide but single-responsibility (SQLite events + meta).
- Meeting pattern tables and title sanitizers are domain density, not accidental complexity.
- `license_check.py` is a standalone gate tool; leave unless SPDX normalization is needed.

**Suggested follow-ups for other audit domains**

- Error-handling: many intentional `except Exception` in AT-SPI/idle (sensor fail-open) — not re-listed here as pure smell.
- Type-safety: `list[Any]` collectors, untyped `agent_worker` (no pyright on system path).
- Axial: surfaces package empty while CLI sits at root — boundary smell adjacent to SM-24.

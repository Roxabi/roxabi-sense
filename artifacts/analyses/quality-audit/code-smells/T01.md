# Code Smells — T1 (tests)

**Partition:** `tests/**/*.py`  
**Scope:** test code quality only (duplication, size, helpers, structure) — not coverage  
**Date:** 2026-07-31  
**Files:** 17 modules (~2.6k LOC), 0 `conftest.py`, 0 `pytest.mark.parametrize`

### Summary

The suite is readable and mostly unit-scoped, but **fixture and mock scaffolding is copy-pasted instead of shared**. The worst hotspot is `test_focus_atspi.py` (~401 LOC): a local `_patch_enrich` helper exists but is used once; eight sibling tests re-paste nearly identical `monkeypatch.setattr` blocks. Cross-file smells include dual daemon modules (`test_daemon` / `test_daemon_loop`) with overlapping `_Boom` / poll-collector assertions, CLI missing-db / invalid-date boilerplate in three modules, and agent-link mock triads repeated across `test_proc.py`. One test (`test_window_from_src_logic`) **does not exercise production code** — it asserts an inline mirror kept “in sync” by comment. There is no shared store fixture, no parametrize usage, and one dead stub file (`test_cli_scaffold.py`). No P0 (no flaky/time-bomb patterns unique to structure; no security in tests). Highest leverage: conftest store fixture + focus enrich fixture + kill false-positive AT-SPI test.

### Recommendations

1. **P1 first — restore trust on AT-SPI worker tests**  
   - Replace/remove `test_window_from_src_logic` so green means production code ran.  
   - Demote `_WORKER.read_text()` substring checks; rely on `FakeProc` + message types already in `test_agent_callback_on_probe_result`.

2. **Introduce `tests/conftest.py` (highest DRY ROI)**  
   - `store` fixture (tmp path DB, auto-close).  
   - Optional `sense_db_env(monkeypatch, path)` for CLI tests.  
   - Optional `patch_focus_enrich(monkeypatch, **overrides)` shared by focus tests.

3. **Collapse focus enrich paste**  
   - Make `_patch_enrich` the default path; accept callables for link/tmux overrides.  
   - Target: each test sets probe + 0–1 overrides, not 4 setattr blocks.

4. **Consolidate overlapping modules**  
   - Merge or clearly split `test_daemon.py` / `test_daemon_loop.py` (shared fakes module).  
   - Move `probe_once` error paths from `test_focus_atspi` → `test_atspi_agent`.  
   - Colocate all `compute_idle_since` / `append_idle_transition` pure tests under idle_facts/idle_transitions.

5. **Parametrize tables**  
   - Title normalize cases, meeting title match/no-match, CLI missing-db per subcommand, agent session missing vs corrupt JSON.

6. **Delete dead weight**  
   - Remove `test_cli_scaffold.py`.  
   - Document fixture/mock conventions in `docs/standards/testing.md` (currently all TODO) so new collectors don’t re-paste.

7. **Size guardrails for tests (soft)**  
   - Prefer modules &lt; ~250 LOC; extract seed builders when scenario setup &gt; ~40 LOC (`_seed` is the good pattern — extend it).  
   - Prefer one behavior per test name when scenarios diverge (missing vs corrupt).

**Out of scope here:** coverage gaps (→ Test Quality domain), production DRY (→ src code-smells), flaky time without freezegun (none observed as structural smell beyond fixed UTC timestamps, which are good).

# Tech Debt — P04 (atspi + util + tools)

**Scope:** `src/roxabi_sense/atspi/**/*.py`, `src/roxabi_sense/util/**/*.py`, `tools/**/*`  
**Also scanned:** tests touching atspi/agent_link/proc/titles  
**Date:** 2026-07-31  
**Method:** module inventory; greps for hard paths, magic timings, type ignores, bare except/pass, version pins, tool script debt

---

### Summary

AT-SPI stack is **feature-rich and empirically tuned** (worker subprocess, name throttling, trace JSONL) with debt in **magic GLib timeouts**, **heavy exception swallowing**, and **system-python FHS assumptions**. Utils are solid but **duplicate hard-coded home/tmux paths** and use **magic scoring weights**. Tools are **quality-gate shell scripts** with no Python tech-debt markers; `license_check.py` is complete. No TODO/FIXME in P4 Python. Risk is **maintainability / portability**, not incomplete product stubs (those sit in P2/P3).

### Recommendations

1. **`resolve_bin` + path SSOT** for tmux/playerctl/python overrides — shared P01/P04 fix.
2. **`SENSE_ATSPI_PYTHON`** mirror of idle python override for non-FHS hosts.
3. **Name and document empirical AT-SPI timings** (50/80 ms, parent walk depth) to reduce “tribal magic.”
4. **Error counters for swallowed AT-SPI exceptions** — keep fail-open sensors, improve `sense status` degraded honesty.
5. **Tools:** no urgent tech debt; keep exemptions list when worker grows past 300 LOC gate.

# Tech Debt — P01 (collectors)

**Scope:** `src/roxabi_sense/collectors/**/*.py`  
**Also scanned:** related tests under `tests/test_*` (agent_sessions, idle, process, focus, mpris patterns)  
**Date:** 2026-07-31  
**Method:** full-file read of collectors; greps for TODO/FIXME/HACK/XXX, stubs, hard-coded paths, magic numbers, dead kinds, incomplete features

---

### Summary

Collectors are largely **implemented and production-shaped** (agent sessions, idle/logind + Wayland watch, focus AT-SPI apply path, MPRIS, process presence, tmux). There are **zero** `TODO`/`FIXME`/`HACK`/`XXX` markers in collector Python. Debt is concentrated in: **legacy API surface** (`claude_history`), **binary path hard-coding** (tmux/playerctl without `PATH` resolve), **snapshot-only kinds with dead timeline kinds**, **magic limits** (PID caps, timeouts), and **config/report decoupling** (idle gap used downstream not owned here). Overall risk: **medium** — nothing blocks phase-1/2 operation, but several footguns will hurt MCP/NATS and multi-host install.

### Recommendations

1. **Binary resolve helper** (tmux, playerctl, optional sense) — highest install-portability win for collectors.
2. **Kill dead kinds or implement them:** reconcile `media` / `agent_session` with what collectors actually write before MCP tools freeze the event vocabulary.
3. **Drop `claude_history`** after one deprecation cycle; tests should use `SessionRegistry` only.
4. **Name magic numbers** used in payloads (`MAX_PIDS`, subprocess timeout) so report/CLI truncation stays consistent.
5. **Do not block collectors on MCP/NATS** — debt is surface-side; collectors are ahead of surfaces (correct axial order).

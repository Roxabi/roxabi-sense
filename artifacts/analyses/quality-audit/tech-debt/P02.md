### Summary

This partition holds the **largest intentional product debt**: MCP is a **CLI stub** (exit 2), NATS is **config skeleton only** (`machine` only; optional extra empty), package version stays **`0.0.1` / “scaffold”** despite a full daemon. Store has **no migrations/retention**. Daemon ships an **unused `FocusEventGate`** (tested, not wired). CLI lives at package root while docs claim `surfaces/`. Severity peaks at **P1** for user-facing incomplete surfaces and **doc/version lie**; correctness risk is lower because stubs fail closed.

### Recommendations

1. **Ship MCP or unpublish the command** — highest user-facing honesty gap after README.
2. **Config honesty pass:** parse/store `nats.enabled=false` defaults; remove fictional `sense config set` from README until real.
3. **Version + README status** — package is past “scaffold”; align narrative with collectors + daemon + recap.
4. **Store lifecycle:** `schema_version` + retention stub before desktop_snapshot volume hurts.
5. **Delete or wire `FocusEventGate`** — orphan tests pretend host-side gating still matters.
6. **Single UTC helper + single threshold constants** — cheap DRY that prevents presence/CLI drift.

# T1 — Test Quality Audit (all tests)

**Domain:** Test Quality  
**Partition:** T1 (`tests/**/*.py` vs `src/roxabi_sense/**/*.py`)  
**Date:** 2026-07-31  
**Method:** Static inventory + import/mapping + flaky/mock/edge-case greps.  
**pytest:** Not executed in this agent session (no shell tool). Cache under `tests/__pycache__` shows prior collection with pytest 9.1.1 / CPython 3.14.

---

### Summary

The suite is **strong on store + report + focus/agent-link unit logic**, with solid `tmp_path` isolation and injected clocks (`now=datetime(...)`) for presence/recap. Coverage is **uneven along the collector axis**: three production collectors (`mpris`, `tmux_sessions`, `idle_watch`) and several daemon glue modules (`daemon_atspi`, `handle_idle_msg`, `load_config`/`paths`) have **no dedicated tests**. Two tests couple to the **real host** (`sense once` with default collectors; `systemctl --user daemon-reload`). Edge cases for empty recap DB, missing Claude session dirs, store write permission failures, and batch rollback are thin or absent. Project testing standards (`docs/standards/testing.md`) are still TODO stubs — no mock/coverage policy.

**Overall grade:** good unit core, **gaps on collectors + config + host-coupled tests** (P1), not a greenfield hole.

### Recommendations

1. **P1 — Close collector axis gaps first** (ADR primary axis): unit tests for `MprisCollector`, `TmuxSessionsCollector`, and pure/helper surface of `IdleWatch` + `handle_idle_msg` (message → store facts). These are production writers today.

2. **P1 — Decouple host-coupled tests**:  
   - Replace `main(["once"])` heartbeat check with `collect_once(SenseConfig(... all off ...))` (already patterned in `test_daemon.py`).  
   - Monkeypatch `systemctl` / `subprocess.run` in install-service CLI test.

3. **P1 — Config/path matrix**: one `test_config.py` + `test_paths.py` with `tmp_path` + env overrides; covers operator-facing misconfig risk.

4. **P2 — Edge case pack** (small, high value):  
   - empty DB → `compile_day_recap` / recap CLI shape  
   - missing `claude_sessions` path (not created)  
   - corrupt Claude `*.json` skipped  
   - `store.batch()` exception → rollback  
   - optional: read-only dir → append fails clearly  

5. **P2 — Daemon glue without GLib**: unit-test `daemon_atspi.handle_atspi_msg` / `apply_probe_result` and idle demotion rebuild policy; leave full `run_daemon` optional.

6. **P2 — Worker purity**: extract pure AT-SPI payload transforms from `agent_worker.py` so they are importable under test without `gi`.

7. **P3 — Hygiene**: remove empty `test_cli_scaffold.py`; fill `docs/standards/testing.md` with project rules:  
   - always `tmp_path` for DB/session fixtures  
   - inject `now`/`ts` for time  
   - mock subprocess at boundary  
   - never real HOME / systemctl in unit suite  
   - collectors: fingerprint + empty/missing tool + error path  

8. **Optional pytest note**: When env allows, run:
   ```bash
   uv run pytest --collect-only -q
   uv run pytest -q
   ```
   Expect ~90+ tests; watch `test_no_heartbeat_kind_from_once` and `test_install_service_cli` for env noise if CI is non-graphical.

### Flaky-pattern checklist (this suite)

| Pattern | Present? | Where |
|---------|----------|-------|
| Real wall clock without `now=` injection | Mild | CLI status age; untested `_utc_stamp` writers |
| Real `HOME` / `Path.home()` session dirs | **Yes** | `test_idle_transitions.test_no_heartbeat_kind_from_once` via default collectors |

| Sleep / timing races | No intentional sleeps | Agent thread `join(timeout=2)` is bounded |

### Positive notes (keep)

- Store tests assert **DB file mode 0o600** and empty meta — security-relevant.
- Presence/recap inject **frozen `datetime`** — anti-flake done right.
- Agent sessions tests cover **corrupt JSON + missing grok + signature skip** — model for other collectors.
- Focus collector tests cover **dedup, mode split (focus/desktop), agent attach, bad probe JSON/timeout**.
- Mocking strategy uses **`monkeypatch` at I/O boundaries** (subprocess, probe, pgrep) rather than mocking the module under test wholesale.
- Failure isolation of `tick_all` / `tick_one` is explicitly tested.

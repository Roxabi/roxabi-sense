# Frontend Patterns — roxabi-sense

**No product frontend.** `frontend.framework: none` in `.claude/stack.yml`.

Surfaces are CLI, stdio MCP, and optional NATS — not a Next/Silex/web app. A future **loopback-only** status page (`127.0.0.1`) would still be an optional binary feature, not a hosted multi-tenant UI.

If you are looking for UX work: stop and re-read `docs/ARCHITECTURE.md` (Rejected: silex-boilerplate).
